# DeepTrace visual contract

Forensic command console for Chandigarh Police Cyber Cell. Nocturnal evidence lab, not a SaaS dashboard.

## Tokens

| Token | Hex | Use |
| --- | --- | --- |
| night | `#071018` | Substrate |
| steel | `#13202C` | Inspector panel |
| graph cyan | `#7EB6C9` | Metadata, hashes, links |
| docket paper | `#E8E0CC` | Forms, login, reports |
| saffron | `#C65A1A` | Priority, overlay, focus |
| verdict red | `#C4312B` | AI-GENERATED |
| verdict green | `#2F8F6A` | REAL |

## Type

- Display: **Barlow Condensed** — duty headings
- Body: **IBM Plex Sans** (+ Devanagari, Gurmukhi)
- Mono: **IBM Plex Mono** — case IDs, SHA-256, custody hashes

## Signature

The **light table**: exhibit on a black stage, manipulation overlay as a slider, hash-chained custody spine on the right. Paper docket for intake. Not a card grid.
